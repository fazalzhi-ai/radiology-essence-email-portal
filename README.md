# Radiology Essence Email Portal

A dedicated Radiology Essence email portal powered by Zoho Mail. It provides a secure and user friendly login interface.

## Email access

The portal redirects users to the official Zoho Mail India sign in page. Passwords are entered only on Zoho and are never collected or stored by this website.

## Hosting

This site is designed for GitHub Pages. Enable Pages from the repository settings using the `main` branch and the root folder.
